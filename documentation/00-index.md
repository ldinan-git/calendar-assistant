# Documentation index

Project: **Tessera** (formerly "margin", briefly "Pascal"), an AI calendar agent you teach in plain English. Class project, built with Claude. Started 2026-10-29.

This folder is a working dump, not a polished write-up. The point is to show the process of working with AI: what was asked, what came back, what was kept, what was thrown out, and what is still unverified.

| File | What's in it |
|---|---|
| `01-conversation-log.md` | The chat that produced the idea, turn by turn, with the user's messages verbatim |
| `02-architecture.md` | Layers, module map, data flow, which parts are code vs LLM |
| `03-fact-schema.md` | The JSON schema for taught facts, examples, open questions |
| `04-mock-layer.md` | How `/responses` and `manifest.json` stand in for the LLM, and where that breaks |
| `05-prompts.md` | The seven prompts, why they look the way they do |
| `06-decisions.md` | Short decision records (what we chose, what we rejected, why) |
| `07-ideas-backlog.md` | Ideas the AI had that aren't built yet |
| `08-ai-collaboration-notes.md` | Where the AI helped, where it was wrong or unverified, how to use it better next time |
| `09-team-structure.md` | The demo cast (you, Jake, Sarah, Alyssa, Priya, Brad) as a diagram, plus how each person changes scheduling. SVG copy: `team-structure.svg` |
| `10-demo-script.md` | The five-part demo script from the new app to the finished product. Generated by `npm run gen:demo` from `src/data/demoScript.js` (the same data drives `/demo.html`) |
| `11-steering-log.md` | **The process.** What I asked, what Claude built first, where I redirected it (with my messages verbatim), where Claude was wrong and who caught it |
| `12-prompt-iterations.md` | **The prompts.** Before and after text pulled from git, the real model outputs that broke them, and what changed in the prompt or in code |

Other places:
- `/summary/walkthrough.md`: the walkthrough, rendered at `/summary.html`
- `/responses`: the canned teaching responses (`extract`) and the manifest that routes them
- `/src/data/graph`: the Outlook / Microsoft Graph style sample calendars, one file per person
- `/scripts`: the Graph data generator and the end-to-end check

## How to run

```bash
npm install
npm run dev          # finished app at :5173/, new app at :5173/fresh.html, script at /demo.html
npm run check:flow   # 109 assertions: data, time zones, knowledge base, validators, scheduling, booking
npm run gen:demo     # regenerate documentation/10-demo-script.md
npm run gen:data     # regenerate src/data/graph/*.json from scripts/gen-graph-data.mjs
```

Live mode (optional, calls the real API from the browser, local demos only):
```bash
cp .env.example .env.local   # set VITE_LLM_MODE=live and VITE_ANTHROPIC_API_KEY
```
Live mode has not been run yet.
